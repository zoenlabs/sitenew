Política de Privacidade

A ZoenLabs valoriza a privacidade e a proteção dos dados pessoais de seus usuários, clientes e parceiros. Esta Política de Privacidade descreve como coletamos, utilizamos, armazenamos e protegemos as informações no uso da plataforma.

1. Quem somos

A ZoenLabs é uma plataforma de tecnologia que oferece soluções de automação, CRM omnichannel, integração com canais de comunicação e uso de inteligência artificial para atendimento.

2. Dados coletados

2.1 Dados fornecidos pelo usuário

  • Nome, e-mail e telefone
  • Dados da empresa (CNPJ, endereço)
  • Informações de login

2.2 Dados coletados automaticamente

  • Endereço IP
  • Dados de navegação
  • Logs de acesso

2.3 Dados de terceiros

Podemos processar dados inseridos por nossos clientes, como informações de contatos e histórico de atendimento.

3. Finalidade do uso dos dados

  • Operação da plataforma
  • Automação de atendimento
  • Comunicação com usuários
  • Integração com serviços externos
  • Melhoria dos serviços

4. Uso de inteligência artificial

A ZoenLabs utiliza IA para automatizar respostas, classificar atendimentos e gerar sugestões. Os dados podem ser processados por provedores externos de IA.

5. Compartilhamento de dados

Podemos compartilhar dados com provedores de infraestrutura, APIs (WhatsApp, Meta, Google) e autoridades legais quando necessário. Não vendemos dados pessoais.

6. Armazenamento e segurança

Adotamos medidas técnicas e administrativas para proteger os dados, incluindo controle de acesso e monitoramento.

7. Direitos dos titulares

Você pode solicitar acesso, correção ou exclusão de dados a qualquer momento.

8. Responsabilidade do cliente

Os clientes são responsáveis pelos dados inseridos e pelo cumprimento da LGPD.

9. Retenção de dados

Os dados são armazenados pelo tempo necessário para cumprir finalidades legais e operacionais.

10. Cookies

Utilizamos cookies para melhorar a experiência do usuário.

11. Alterações

Esta política pode ser atualizada periodicamente.
